# Module 3 interactive example

This directory contains a self-contained static report for comparing regulatory-topic solutions across K = 20, 30, and 32. The report and its `hpa_assets` directory must be deployed together.

The GitHub Pages workflow publishes the example at:

`https://oncologylab.github.io/craftgrn/examples/module3-topic-model/`

For local review, serve the repository over HTTP and open the report through the server rather than directly from the filesystem.
